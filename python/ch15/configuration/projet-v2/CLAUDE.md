# Logiciel des contrats de Kanvô Assurances

Ancien logiciel de la DSI (2011), en Python, sans tests automatiques. Organisation des dossiers : @LISEZMOI.txt

## Travailler sur ce dépôt

- Lancer depuis ce dossier : `python lancer.py`. Une base de recette se crée avec `python lancer.py creer-base`.
- Pas de tests automatiques : dites comment vérifier votre changement à la main, sur la base de recette.
- Les règles propres à un dossier sont dans `.claude/rules/` : elles se chargent quand vous travaillez sur ses fichiers.
- Ne modifiez que ce que la demande vise ; signalez ce qui vous semble faux ailleurs, sans le corriger.
