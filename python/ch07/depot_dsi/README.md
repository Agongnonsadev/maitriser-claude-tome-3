# Outils de l'équipe informatique de Kanvô Assurances (fictif)

Dépôt de l'équipe informatique. Les données sont fabriquées pour le livre.

- `exports/` : extractions du logiciel de gestion, pour les tableaux de bord de la direction.
- `.mcp.json` : le serveur MCP du système de gestion, pour Claude Code. Le jeton de chacun vient de
  son environnement (`KANVO_JETON`), jamais de ce dépôt.
